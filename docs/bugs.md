# 不具合・課題ログ

このアプリは `docs/SPEC.md` が設計判断・変更履歴の正本のため、設計判断はそちらに
一本化しています（このファイルとの二重管理を避けるため、decisions.md/timeline.mdは
あえて作っていません）。ここでは実機で見つかった不具合と対応だけを記録します。

## 解決済み

- **S2でマイクの自動確定がTTSを追い越す暴走**: マイクの自動確定(2500ms)がTTSの発話を
  追い越して次の行に進んでしまい、iOSの`cancel`直後に`speak`が握り潰される挙動と
  連鎖して暴走していた。`setAutoClose`と`rep`の出どころを導入して解決

## 既知の制約

- Chromeは15秒以上の連続発話で停止する既知バグがある。再生中は10秒ごとに
  詳細は`docs/SPEC.md`を参照
